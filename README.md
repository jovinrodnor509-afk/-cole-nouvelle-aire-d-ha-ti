# École Nouvelle Ayiti

Platfòm aprantisaj an Kreyòl pou Primè, Segondè, ak Metye (kouti, mekanik, elektrisite, kwafi, kwizin).

## Estrikti (vèsyon plat — san okenn dosye)

Tout fichye yo nan **menm nivo**, pa gen `css/` ni `js/` — sa fèt espre pou evite pwoblèm upload sou telefòn.

```
index.html      → Paj prensipal (twa chemen yo)
style.css       → Tout style/koulè
main.js         → Lojik front-end (byento: auth, aksè peye)
firebase-config.js → Konfigirasyon Firebase (deja gen vrè valè w yo ladan)
prime.html      → Plasholder seksyon Primè
segonde.html    → Plasholder seksyon Segondè
metye.html      → Plasholder seksyon Metye
README.md       → Dokiman sa a
```

## Deplwaman — METÒD PI FASIL sou telefòn
1. Nan repo a, efase TOUT ansyen fichye/dosye ki la deja (README.md, index.html, elt., ak nenpòt dosye css/js si yo rete)
2. "Add file" → "Upload files"
3. Trennen **7 fichye yo** (pa gen dosye pou trennen, se sèlman fichye grenn) nan menm kou a
4. "Commit changes"
5. Settings → Pages → Branch `main`, `/(root)` → Save

Kòm pa gen dosye ditou, pwoblèm "fichye ki tounen plat" la pa ka rive ankò — se deja konsa nou vle l la.

## Pwochèn etap
- Konekte MonCash (gade dosye `moncash-integration` ou te resevwa anvan an)
- Ranpli Primè a ak vrè kontni an premye
